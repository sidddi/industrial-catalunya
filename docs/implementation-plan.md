# Decisions
- Empty workspace. TypeScript + static HTML generation + esbuild, not Next.js: smaller prototype, no backend, all SEO routes prerendered. Browser app bundles the same deterministic engine tested in Node. Versions were read from npm on 07/10/2026 and lockfile pins dependencies.
- Six verified options. Prioritize exact admission codes; do not present Manresa or UdL standalone mechanics using grouped-entry cutoffs without matching those routes. These are future research, not absent universities.
- Originals in sources/, separate dataset tables, review-only importer, strict runtime validation.
- Calculate and validate before styling. No deploy, git push, account connection, purchases, ads or analytics.
- ADS_ENABLED=false is fixed for this prototype; no ad integration can be enabled by a flag alone. Deliberate safety gate.
